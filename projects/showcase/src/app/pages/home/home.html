Almacenamiento tipado para Angular

ngx-uceva-storage-manager es una librería de Angular que ofrece una API tipada para gestionar LocalStorage y Cache Storage. Centraliza la serialización, el prefijo de las claves de LocalStorage y el manejo de errores para que las aplicaciones no dependan directamente de las APIs del navegador.

Instala la librería en tu proyecto:

npm install ngx-uceva-storage-manager

LocalStorage

Guarda, consulta, actualiza y elimina valores tipados de forma síncrona. Incluye operaciones para comprobar claves, listarlas y limpiar el almacenamiento.

Cache Storage

Gestiona cachés de recursos con una API asíncrona basada en promesas. Permite crear cachés, guardar respuestas, recuperar JSON y eliminar recursos.
